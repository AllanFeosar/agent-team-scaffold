# Security backlog — Low and Info findings

Save as `docs/security-backlog.md` (or wherever the project keeps plans). A finding rated Low or Info goes **here**,
not into the work queue: it does not start a fix round, does not block a merge, and does not outrank a roadmap item.
Review the file when planning, and promote an entry to the queue only if (a) it has become Medium or above, (b) it
blocks a release, or (c) it sits on a path you are about to change anyway.

Plain bullets on purpose, not checkboxes: the orchestrator treats every `- [ ]` line in `STATUS.md` as work to do.
